1 הנחיות כלליות לסטודנטים

בכל שאלה נבקש לעבוד בשיטה מסודרת: (1) הגדרת המשימה, (2) נתונים ונעלמים, (3) תרשים תהליך, (4) בחירת מערכת גבולות והנחות, (5) ניתוח דרגות חופש, (6) כתיבת משוואות, (7) פתרון מספרי ובדיקות. המטרה היא לבנות מיומנות שיטתית, לא רק להגיע לתשובה.

2 תרגיל 1: מיקסר פשוט (יחידה אחת, ללא תגובה)

תיאור התהליך: שני זרמים נוזליים של אתנול-מים נכנסים למערבל. הזרם היוצא הוא תערובת הומוגנית.

נתונים: - זרם 1: (m_1 = 120  ), שבר מסה של אתנול (w_{E,1}=0.25) (יתר הזרם מים). - זרם 2: (m_2 = 80  ), שבר מסה של אתנול (w_{E,2}=0.60). - מצב עמיד, ללא איבודים, ללא תגובה.

מבוקש: 1. ספיקת המסה של הזרם היוצא (m_3). 2. שבר המסה של אתנול בזרם היוצא (w_{E,3}). 3. ספיקת המסה של מים בזרם היוצא.

פתרון מלא - תרגיל 1

2.1 1) הגדרת המשימה

לחשב ספיקת יציאה והרכב יציאה ממאזן מסה כולל ומאזן רכיב (אתנול), במערכת יחידה ללא תגובה.

2.2 2) נתונים ונעלמים

נתונים: (m_1, m_2, w_{E,1}, w_{E,2}).
נעלמים: (m_3, w_{E,3}), וגם (m_{W,3}) (מים ביציאה).

2.3 3) תרשים תהליך

מיקסר: (1 + 2 ).

2.4 4) מערכת גבולות והנחות

גבול סביב המיקסר. הנחות: מצב עמיד, אין איבודי מסה, אין תגובה, אין זרמי צד.

2.5 5) ניתוח דרגות חופש (DOF)

נעלמים עיקריים: (m_3, w_{E,3}) (2).
משוואות בלתי תלויות: מאזן מסה כולל (1) + מאזן אתנול (1) = 2.
לכן (DOF = 2-2=0) (פתיר חד משמעית).

2.6 6) כתיבת משוואות

מאזן מסה כולל:
[ m_3 = m_1 + m_2 ] מאזן אתנול:
[ m_3 w_{E,3} = m_1 w_{E,1} + m_2 w_{E,2} ]

2.7 7) פתרון מספרי

[ m_3 = 120 + 80 = 200   ] ספיקה אתנול נכנסת: [ m_{E,in}=120 + 80 = 30 + 48 = 78   ] לכן: [ w_{E,3}==0.39 ] מים ביציאה: [ m_{W,3} = m_3(1-w_{E,3}) = 200(1-0.39)=200=122   ]

תשובות: (m_3=200  ), (w_{E,3}=0.39), (m_{W,3}=122  ).

3 תרגיל 2: ספליטר (יחידה אחת, ללא תגובה)

תיאור התהליך: זרם גז נכנס למפצל (Splitter) שמחלק אותו לשני זרמים, ללא שינוי בהרכב.

נתונים: - זרם כניסה 1: (n_1 = 50  ). - הרכב מולרי בכניסה: (y_{A,1}=0.70), (y_{B,1}=0.30). - יחס פיצול: ( n_2 = 0.35 n_1). הזרם השני הוא (n_3). - מצב עמיד, ללא תגובה.

מבוקש: 1. (n_2, n_3) 2. (n_{A,2}, n_{B,3}) 3. ההרכבים (y_{A,2}), (y_{A,3})

פתרון מלא - תרגיל 2

3.1 1) הגדרת המשימה

מפצל שומר הרכב: (y) זהה בכל הזרמים. נחשב ספיקות ותתי-ספיקות.

3.2 2) נתונים ונעלמים

נתונים: (n_1, y_{A,1}, y_{B,1}, n_2 = 0.35n_1).
נעלמים: (n_2, n_3, n_{A,2}, n_{B,3}, y_{A,2}, y_{A,3}).

3.3 3) תרשים תהליך

Splitter: (1 + 3).

3.4 4) מערכת גבולות והנחות

גבול סביב המפצל. הנחות: מצב עמיד, אין תגובה, אין איבודים, ההרכב נשמר.

3.5 5) DOF

בפועל מספיקים: מאזן כולל + נתון יחס פיצול + עובדת “הרכב נשמר”. המערכת פתירה.

3.6 6) משוואות

נתון יחס פיצול: [ n_2 = 0.35n_1 ] מאזן כולל: [ n_1 = n_2 + n_3 ] הרכב נשמר: [ y_{A,2}=y_{A,3}=y_{A,1}=0.70,y_{B,2}=y_{B,3}=0.30 ] תתי-ספיקות: [ n_{A,2}=n_2 y_{A,2},n_{B,3}=n_3 y_{B,3} ]

3.7 7) פתרון מספרי

[ n_2 = 0.35 = 17.5   ] [ n_3 = 50 - 17.5 = 32.5   ] [ n_{A,2}=17.5 = 12.25   ] [ n_{B,3}=32.5 = 9.75   ] וההרכבים: [ y_{A,2}=y_{A,3}=0.70 ]

תשובות: (n_2=17.5), (n_3=32.5  ), (n_{A,2}=12.25  ), (n_{B,3}=9.75  ), (y_{A,2}=y_{A,3}=0.70).

4 תרגיל 3: שתי יחידות ברצף (מיקסר + מפריד אידאלי), ללא תגובה

תיאור התהליך: שני זרמים נכנסים למיקסר. התערובת עוברת למפריד אידאלי שמחזיר רכיב אחד נקי בזרם עליון ואת שאר הרכיבים בזרם תחתון.

נתונים: - זרם 1: (n_1 = 40  ), הרכב: (y_{A,1}=0.50), (y_{B,1}=0.50). - זרם 2: (n_2 = 60  ), הרכב: (y_{A,2}=0.20), (y_{B,2}=0.80). - מפריד אידאלי: כל (A) יוצא בזרם 4 (עליון) כ-(A) טהור, וכל (B) יוצא בזרם 5 (תחתון) כ-(B) טהור. - מצב עמיד, ללא איבודים, ללא תגובה.

מבוקש: 1. הספיקה וההרכב ביציאת המיקסר (זרם 3). 2. (n_4), (n_5) וההרכבים שלהם.

פתרון מלא - תרגיל 3

4.1 1) הגדרת המשימה

לחשב זרם ביניים (אחרי מיקסר) ואז לבצע הפרדה מושלמת לשני רכיבים.

4.2 2) נתונים ונעלמים

נתונים: (n_1, n_2, y_{A,1}, y_{A,2}) (ומכאן (y_B)).
נעלמים: (n_3, y_{A,3}), ואז (n_4, n_5).

4.3 3) תרשים תהליך

(1 + 2 ) (מיקסר), ואז (3 (A ) + 5(B )).

4.4 4) מערכת גבולות והנחות

נוח לעשות בשתי מערכות גבולות: (א) סביב המיקסר, (ב) סביב המפריד. הנחות: מצב עמיד, אין איבודים, אין תגובה, הפרדה אידאלית.

4.5 5) DOF

מיקסר: נעלמים (n_3, y_{A,3}) (2), משוואות: כולל + רכיב (A) (2) => (DOF=0).
מפריד: נעלמים (n_4, n_5) (2), משוואות: מאזן (A) + מאזן (B) (2) => (DOF=0).

4.6 6) משוואות

מיקסר:
[ n_3 = n_1 + n_2 ] [ n_3 y_{A,3} = n_1 y_{A,1} + n_2 y_{A,2} ]

מפריד אידאלי:
מאחר שכל (A) הולך לזרם 4: [ n_4 = n_3 y_{A,3} ] וכל (B) לזרם 5: [ n_5 = n_3 y_{B,3} = n_3(1-y_{A,3}) ] וההרכבים: [ y_{A,4}=1, y_{B,4}=0,y_{A,5}=0, y_{B,5}=1 ]

4.7 7) פתרון מספרי

מיקסר: [ n_3 = 40+60 = 100   ] [ n_3 y_{A,3} = 40 + 60 = 20 + 12 = 32 y_{A,3}=0.32 ] מפריד: [ n_4 = 100 = 32   ] [ n_5 = 100 = 68   ]

תשובות: זרם 3: (n_3=100), (y_{A,3}=0.32). זרם 4: (n_4=32 ), (A) טהור. זרם 5: (n_5=68 ), (B) טהור.

5 תרגיל 4: ריאקטור עם תגובה אחת (יחידה אחת, המרה נתונה)

תיאור התהליך: ריאקטור רציף (CSTR/PFR לא משנה למאזן חומר כולל) שבו מתרחשת תגובה אחת: [ A B ] אין רכיבים נוספים.

נתונים: - זרם כניסה: (n_{A,in} = 120  ) (טהור (A)). - המרה חד-מעבר (Single-pass conversion) של (A): (X_A = 0.45). - מצב עמיד.

מבוקש: 1. ספיקות (A) ו-(B) ביציאה. 2. היקף תגובה () (בקצב של ()). 3. בדיקת מאזן כולל (מולרי).

פתרון מלא - תרגיל 4

5.1 1) הגדרת המשימה

לקשר בין המרה, היקף תגובה והרכבים ביציאה עבור תגובה יחידה.

5.2 2) נתונים ונעלמים

נתונים: (n_{A,in}), (X_A).
נעלמים: (n_{A,out}), (n_{B,out}), ().

5.3 3) תרשים תהליך

ריאקטור: (A_{in} A_{out}+B_{out}).

5.4 4) מערכת גבולות והנחות

גבול סביב הריאקטור. הנחות: מצב עמיד, אין תגובות אחרות, אין זרמי צד, אין הצטברות.

5.5 5) DOF

נעלמים: 3.
משוואות: קשר המרה (1) + סטויכיומטריה דרך היקף תגובה עבור (A) ו-(B) (2) => 3.
(DOF=0).

5.6 6) משוואות

הגדרת המרה: [ X_A= n_{A,out}=n_{A,in}(1-X_A) ] היקף תגובה לפי סטויכיומטריה (A=-1, B=+1): [ n{A,out}=n{A,in}+A = n{A,in}- ] [ n_{B,out}=n_{B,in}+_B = 0+ ]

[ n_{A,out}=120(1-0.45)=120=66   ] מכאן: [ =n_{A,in}-n_{A,out}=120-66=54   ] ולכן: [ n_{B,out}=54   ] בדיקת מאזן מולרי כולל: לפני: (120). אחרי: (66+54=120). תקין.

תשובות: (n_{A,out}=66), (n_{B,out}=54  ), (  ).

6 תרגיל 5: ריאקטור עם שתי תגובות מקבילות (תגובות מרובות, יחידה אחת)

תיאור התהליך: בריאקטור מתרחשות שתי תגובות מקבילות: [ A B ] [ A C ] אין רכיבים נוספים. הזרם הנכנס טהור (A).

נתונים: - (n_{A,in} = 200  ). - ההמרה הכוללת של (A): (X_A = 0.60). - מתוך (A) שנצרך, 70% הולך ל-(B) ו-30% ל-(C) (חלוקת תוצרים לפי צריכת (A)).

מבוקש: 1. (n_{A,out}, n_{B,out}, n_{C,out}). 2. קצבי היקף תגובה (_1, _2). 3. ניתוח DOF קצר שמסביר למה הנתונים מספיקים.

פתרון מלא - תרגיל 5

6.1 1) הגדרת המשימה

לפתור מערכת עם שתי תגובות מקבילות באמצעות המרה כוללת וחלוקת צריכת המגיב בין הנתיבים.

6.2 2) נתונים ונעלמים

נתונים: (n_{A,in}), (X_A), חלוקה 70/30 של (A) הנצרך.
נעלמים: (n_{A,out}, n_{B,out}, n_{C,out}, _1, _2).

6.3 3) תרשים תהליך

ריאקטור יחיד: (A A+B+C) (למעשה (A) חלקו לא מגיב וחלקו הופך ל-(B) או (C)).

6.4 4) מערכת גבולות והנחות

גבול סביב הריאקטור. הנחות: מצב עמיד, רק שתי תגובות נתונות, אין רכיבים נוספים, אין זרמי צד.

6.5 5) DOF

אפשר להסתכל כך:
- המרה כוללת נותנת את כמות (A) שנצרכה.
- חלוקת 70/30 קובעת כמה מהצריכה שייכת לכל תגובה, כלומר קובעת (_1, _2).
- ואז הסטויכיומטריה קובעת את התוצרים.
לכן המידע מספיק לפתרון מספרי חד משמעי.

6.6 6) משוואות

צריכת (A): [ n_{A,cons}=X_An_{A,in} ] יציאת (A): [ n_{A,out}=n_{A,in}-n_{A,cons} ] חלוקת צריכה: [ 1 = 0.70n{A,cons},2 = 0.30n{A,cons} ] מאזן יצירה לתוצרים (כי (_B=+1) ב-R1, (C=+1) ב-R2): [ n{B,out}=1,n{C,out}=_2 ]

6.7 7) פתרון מספרי

[ n_{A,cons}=0.60 = 120   ] [ n_{A,out}=200-120 = 80   ] [ 1=0.70 = 84  ,2=0.30 = 36   ] [ n{B,out}=84,n{C,out}=36   ] בדיקת מולרי כולל: לפני (200). אחרי (80+84+36=200). תקין.

תשובות: (A_{out}=80), (B_{out}=84), (C_{out}=36  ). (_1=84), (_2=36  ).

7 תרגיל 6: מערכת מרובת יחידות עם שתי תגובות, תחזיר וזרם טיהור (דגל-שדה)

תיאור התהליך (סיפור תהליכי): במפעל מייצרים תוצר רצוי (P) ממגיב (A) וגז מחמצן (O_2). בריאקטור מתקיימות שתי תגובות במקביל: תגובה רצויה שמייצרת (P) ותגובה בלתי רצויה שמייצרת תוצר לוואי (S). בתום הריאקטור התוצרים עוברים למפריד שמחזיר את כל (A) שלא הגיב חזרה לתחזיר, בעוד שכל (P) ו-(S) יוצאים במוצר. בגלל כניסת גז אינרטי (I) עם המחמצן (למשל חנקן או ארגון) חייבים טיהור (Purge) של חלק מהגזים כדי למנוע הצטברות אינרט.

תגובות בריאקטור: [ A + O_2 P ] [ A + O_2 S ]

נתונים: - זרם טרי 1 (Fresh feed): (A) טהור בקצב (n_{A,f} = 100  ). - זרם טרי 2 (Oxidant feed): תערובת גז עם (y_{O_2}=0.90), (y_I=0.10) וקצב כולל (n_{ox,f}=200  ). - תחזיר: אחרי הפרדה כל (A) שלא הגיב חוזר לכניסה (לפני הריאקטור). - טיהור: לפני החזרה לתחזיר, מפצלים את זרם הגז החוזר כך ש-10% ממנו נזרק כזרם טיהור (purge), ו-90% חוזר כתכזיר. - בריאקטור (חד-מעבר ביחס ל-(A) שנכנס לריאקטור): ההמרה הכוללת של (A) היא (X_A=0.50). - מתוך (A) שנצרך בריאקטור, 80% הולך לתגובה R1 ו-20% לתגובה R2. - המפריד אידאלי: כל (P) ו-(S) יוצאים במוצר; לא חוזרים לתחזיר. כל (A) שלא הגיב ממשיך לזרם גז שממנו עושים purge+recycle. (O_2) ו-(I) נשארים בגז (כלומר לא יוצאים במוצר).

מבוקש: 1. הספיקות הנכנסות לריאקטור: (n_{A,in}), (n_{O_2,in}), (n_{I,in}). 2. קצבי יציאה מהמוצר: (n_P), (n_S). 3. ספיקת (A) בזרם הטיהור. 4. הסבר DOF עבור המערכת הכוללת (למה יש מספיק נתונים).

פתרון מלא - תרגיל 6

7.1 1) הגדרת המשימה

מערכת עם: (א) ערבוב זרמים טריים עם תחזיר, (ב) ריאקטור עם שתי תגובות, (ג) מפריד אידאלי שמחזיר (A) בלבד לגז, (ד) מפצל purge/recycle שמונע הצטברות אינרט. המטרה: לחשב ספיקות steady-state.

7.2 2) נתונים ונעלמים

נתונים טריים: (n_{A,f}=100), (n_{ox,f}=200), (y_{O_2}=0.90), (y_I=0.10).
נתונים תפעוליים: purge = 10% מהגז החוזר, (X_A=0.50) על כניסת הריאקטור, חלוקה 80/20 לצריכת (A).
נעלמים מרכזיים: (n_{A,in}) לריאקטור (כולל תחזיר), ספיקות גזים במעגל (recycle/purge), ספיקות תוצרים (P,S), ספיקות (O_2) ו-(I) בכניסה לריאקטור.

7.3 3) תרשים תהליך (טקסטואלי)

Fresh (A) + Fresh oxidant () Mixer () Reactor () Separator () Gas stream (A unreacted + O2 + I) () Splitter (10% purge, 90% recycle) () חזרה למיקסר.
Product stream: (P+S).

7.4 4) בחירת מערכת גבולות והנחות

נעבוד בשתי רמות:
- מערכת כוללת מסביב לכל התהליך (כולל purge): במצב עמיד לא יכולה להיות הצטברות של (I), ולכן (I) חייב לצאת רק דרך purge.
- מערכת מסביב לריאקטור: משתמשים בהמרה והחלוקה לנתיבי תגובה כדי לחשב צריכת (A) ו-(O_2) ויצירת (P,S).
הנחות: מצב עמיד, מפריד אידאלי לפי הנתון, אין איבודים אחרים, אין תגובות נוספות.

7.5 5) DOF (הסבר קצר ומכוון)

ה”טריק” הוא שהאינרט (I) מכתיב את זרם הגז במעגל: במצב עמיד כל (I) שנכנס חייב לצאת ב-purge, כי הוא לא נצרך ולא יוצא במוצר. זה נותן ישירות את כמות הזרם המנוקה, וממנה את הזרם הממוחזר. אחרי שיש לנו את זרם ה-(A) הממוחזר, אפשר לקבוע את (n_{A,in}) לריאקטור ואז לחשב הכל דרך (X_A) וחלוקת 80/20. לכן הנתונים מספיקים לפתרון.

7.6 6) כתיבת משוואות

שלב א: לפרק את זרם המחמצן הטרי
[ n_{O_2,f} = 0.90 = 180   ] [ n_{I,f} = 0.10 = 20   ]

שלב ב: מאזן אינרט על המערכת הכוללת
האינרט לא נצרך ולא יוצא במוצר, לכן: [ n_{I,purge} = n_{I,f} = 20 ] אבל purge הוא 10% מזרם הגז לפני הפיצול (נסמן אותו (G)). מאחר שהפיצול הוא “יחס ספיקות” והוא לא משנה הרכב, מתקיים: [ n_{I,purge} = 0.10 n_{I,G} n_{I,G} = = 200 ] זרם האינרט שממוחזר (90%): [ n_{I,recycle}=0.90 = 180 ] ולכן האינרט בכניסה לריאקטור הוא סכום הטרי והממוחזר: [ n_{I,in} = n_{I,f} + n_{I,recycle} = 20 + 180 = 200 ]

שלב ג: קשר בין (n_{A,in}) לבין תחזיר (A)
נסמן (n_{A,in}) ככניסת (A) לריאקטור (טרי + תחזיר). ההמרה: [ n_{A,cons} = X_A n_{A,in} = 0.50n_{A,in} ] לכן (A) שלא הגיב: [ n_{A,unreacted} = n_{A,in} - n_{A,cons} = 0.50n_{A,in} ] לפי הנתון, כל (A) שלא הגיב עובר לזרם הגז (G), ואז 90% ממוחזר: [ n_{A,recycle} = 0.90 n_{A,unreacted} = 0.90n_{A,in}=0.45n_{A,in} ] ומאזן ערבוב לכניסת הריאקטור: [ n_{A,in} = n_{A,f} + n_{A,recycle} = 100 + 0.45n_{A,in} ] לכן: [ n_{A,in}(1-0.45)=100 n_{A,in}=100 n_{A,in}==181.818   ] ומיד: [ n_{A,cons}=0.50 = 90.909   ] [ n_{A,unreacted}=90.909   ] [ n_{A,purge} = 0.10n_{A,unreacted} = 9.091   ]

שלב ד: חלוקת צריכת (A) בין תגובות וקצבי יצירת תוצרים
[ 1 = 0.80 n{A,cons} = 0.80 = 72.727   ] [ 2 = 0.20 n{A,cons} = 0.20 = 18.182   ] מאחר שב-R1 מתקבל (P) בקצב (_1), וב-R2 מתקבל (S) בקצב (_2): [ n_P = 72.727,n_S = 18.182   ]

שלב ה: חישוב צריכת (O_2) ובדיקת היתכנות עם מחמצן טרי
צריכת (O_2) לפי סטויכיומטריה: ב-R1 נצרך 1 מול (O_2) לכל מול (A), וב-R2 נצרך 0.5 מול (O_2) לכל מול (A): [ n_{O_2,cons} = 11 + 0.52 = 72.727 + 0.5 = 72.727 + 9.091 = 81.818   ] בכניסה יש לפחות (n{O_2,f}=180). גם אם אין מחמצן ממוחזר בכלל, יש מספיק (O_2). במערכת שלנו יש גם (O_2) שיכול להצטבר במעגל, אבל בניגוד ל-(I), הוא יכול להישאר עודף ועדיין לצאת ב-purge. כדי לענות על סעיף (1) מספיק לחשב מינימום: [ n{O_2,in}   ] אם מניחים (בפשטות) שאין שליטה נוספת והריאקטור “מקבל” את מה שמגיע מהמיקסר, אז: [ n_{O_2,in} = n_{O_2,f} + n_{O_2,recycle} ] כדי לא להיכנס לאינסוף אפשר להשאיר את (n_{O_2,in}) כ”תלוי במאזן המעגל” ולדווח תוצאה שימושית: צריכת (O_2) היא (81.818) ולכן עודף מחמצן משמעותי קיים.

כדי בכל זאת לתת ערך מלא ל-(n_{O_2,in}) נשתמש בהנחה נפוצה לתרגיל: “אין מיחזור של (O_2) בכוונה, כלומר מתכננים כך שהמפריד/החזרה נוגעים רק ל-(A)”. תחת הנחה זו: [ n_{O_2,in}=n_{O_2,f}=180,n_{I,in}=200 ] ואז ביציאה מהריאקטור: [ n_{O_2,out}=180-81.818=98.182   ] והוא יוצא בסוף גם דרך purge וגם דרך recycle לפי 10/90 (אבל זה כבר לא נדרש לסעיפים).

8 הערה פדגוגית קצרה למרצה (אופציונלי להכללה בספר)

תרגיל 6 בנוי כך ש-(I) (אינרט) הוא “המפתח” שמונע מהסטודנטים ללכת לאיבוד: הוא מכריח מאזן מערכת כולל עם purge, ואז כל השאר נופל כמו דומינו. זו בדיוק המיומנות שאנחנו רוצים בפרק 4: לבחור מערכת גבולות חכמה ולזהות רכיב שמספק משוואה חזקה.
